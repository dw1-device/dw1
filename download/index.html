下載後解壓縮，先打開「先讀我」安裝說明，照步驟做約 15 分鐘。用手機或平板玩、或者不用 RetroArch？請用網頁版（上載記憶卡存檔即可，不用安裝）。

需要甚麼

  • RetroArch，PS1 核心用 Beetle PSX、SwanStation 或 PCSX ReARMed，並在設定 → 網絡開啟「網絡指令」
  • Python 3（免費，從官方網站安裝；Mac 也可用 Apple 提供的版本）
  • 遊戲：數碼暴龍世界 日版 Rev 1（SLPS-01797），或用它製作的繁體中文漢化版。網頁會自動偵測版本，漢化版會顯示遊戲內的用字

安全嗎？

  • 沒有 .exe／.app：全部是可以用記事本或文字編輯打開檢查的純文字檔
  • 不連接互聯網：只和你自己電腦上的 RetroArch 溝通
  • 只讀不寫：不會改動遊戲、存檔或任何檔案，不需要管理員權限；不想用了，刪除資料夾即可
  • 第一次打開啟動檔時，Mac 和 Windows 會對網上下載的檔案顯示警告，這是正常的保護措施，安裝說明有教你怎樣處理

使用流程

  1. 開 RetroArch，載入遊戲，進入可以操控精靈的畫面（不需要先存檔）
  2. 雙擊啟動檔，小程式視窗出現「已連接 RetroArch」
  3. 瀏覽器開 http://127.0.0.1:55356/，左上角出現綠點就是實時中
  4. 想用 iPad／手機做副螢幕：改用「iPad 也可以看」的啟動檔
