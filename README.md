# DW1 暴龍機・網頁版

《數碼暴龍世界》（Digimon World，PS1 日版 Rev 1，SLPS-01797）的育成輔助工具。

**👉 開始使用：<https://dw1-device.github.io/dw1/>**

非官方愛好者作品，免費使用，歡迎分享。

## 可以做甚麼

- **上載存檔分析**：讀取記憶卡存檔（.mcr／.mcd／.srm／.mcs／.psv／.gme 等），自動帶入精靈的能力、年齡、壽命、背包、已學招式和已加入城鎮的同伴。
- **進化預測**：照遊戲程式的判定方法，預測會進化成哪一隻；也可以選擇目標，模擬需要的訓練，並判斷能不能做到。
- **其他**：訓練計劃、招式查詢、戰鬥學招和智力學招機率、道具、地圖、繁榮度、開始之街食堂、鬥技場賽程。

## 上載存檔：你的資料去了哪裡？

可以放心上載：

- **只在你的裝置上處理**：存檔由你的瀏覽器直接讀取和分析，**不會上載**到任何伺服器，也不會傳送給作者或任何第三方。
- **不會改動你的存檔**：網頁只會讀取，絕不會修改或覆寫你的記憶卡檔案。
- **留底在哪裡**：讀到的數值（例如精靈能力、勾選的同伴）只儲存在**你自己瀏覽器的本機儲存空間**，方便下次打開時繼續使用。這些資料不會離開你的裝置；清除瀏覽器的網站資料就會全部刪除。
- **沒有追蹤**：網頁不使用 cookies、沒有廣告、沒有分析或追蹤程式，也不會從其他網站載入任何字型、程式或圖片。
- **可以離線使用**：整個工具只是一個 `index.html` 檔案。你可以下載這個檔案，在沒有網絡的情況下直接用瀏覽器打開。
- **網站主機的說明**：網頁放在 GitHub Pages。和所有網站一樣，GitHub 的伺服器會按其私隱政策記錄一般的連線資料（例如 IP 位址），但看不到你的存檔內容，因為存檔從來沒有傳送出去。

## 資料來源

攻略內容和進化條件等資料，整合自多年來網上玩家的研究和攻略，並盡可能和遊戲檔案（日版 Rev 1）核對。即使如此，部分資料仍可能需要修正或補充。

**資料修正建議：** 如果發現資料有誤或可以補充，歡迎到 [Issues → 資料修正建議](https://github.com/dw1-device/dw1/issues/new/choose) 填寫表格（需要免費的 GitHub 帳戶）。請盡量寫明在哪一頁、哪一項，以及正確資料或你在遊戲中看到的情況；附上截圖會更有幫助。
