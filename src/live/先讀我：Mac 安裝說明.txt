DW1 暴龍機 實時版　Mac 安裝說明
==================================================

照下面 1 → 6 步做，大約 15 分鐘。
遇到問題，請把「畫面上的字」截圖，並說明做到第幾步。


這是甚麼？
  你用 RetroArch 或 DuckStation 玩《數碼暴龍世界》（PS1 日版 Rev 1 或其繁體中文漢化版）時，
  這個工具會即時讀出遊戲裏的數值（能力、疲勞、失誤、背包等），在瀏覽器
  網頁上自動更新，還會提示精靈肚餓、想大便、想睡，以及進化預測。

安全嗎？
  ✔ 沒有 .app 或其他執行檔。資料夾裏全部是可以用「文字編輯」打開檢查的純文字檔。
  ✔ 不連接互聯網，只和你電腦上的模擬器（RetroArch 或 DuckStation）溝通。
  ✔ 只讀不寫：不會改動遊戲、存檔或任何檔案，不需要管理員權限。
  ✔ 不想用了，刪除整個資料夾即可。


--------------------------------------------------
第 1 步：解壓縮
--------------------------------------------------
  雙擊下載的 .zip 檔案，會得到一個資料夾，把它放到「桌面」或「文件」。
  資料夾裏應該有：
    index.html
    dw1_bridge.py
    Mac 啟動（只限這部電腦）.command
    Mac 啟動（iPad 也可以看）.command
    先讀我：Mac 安裝說明.txt（就是這份）
    使用說明.txt（完整版說明，遇到問題時參考）


--------------------------------------------------
第 2 步：準備 Python 3（只需做一次）
--------------------------------------------------
  1. 打開「終端機」（應用程式 → 工具程式 → 終端機）。
  2. 輸入 python3 --version 然後按 Enter。
     ・顯示「Python 3.x.x」：已經有了，跳到第 3 步。
     ・彈出視窗要求安裝「命令列開發者工具」：按「安裝」，等它完成
       （這是 Apple 官方提供的，約幾分鐘）。
     ・也可以到 https://www.python.org/downloads/macos/ 下載安裝。


--------------------------------------------------
第 3 步：設定模擬器（只需做一次，RetroArch 或 DuckStation 擇一）
--------------------------------------------------
  需要：RetroArch、PS1 核心、PS1 日版 BIOS（例如 scph5500.bin）、
        遊戲《數碼暴龍世界》日版 Rev 1（SLPS-01797）或其繁體中文漢化版。
        其他版本讀不到。

  1. 下載核心：
     主選單 → 線上更新（Online Updater）→ 核心下載器（Core Downloader）
     →「Sony - PlayStation (Beetle PSX HW)」或「Beetle PSX」
     （也可以用 SwanStation 或 PCSX ReARMed 核心）
  2. 開啟「網絡指令」：
     主選單 → 設定（Settings）→ 網絡（Network）
     →「網絡指令」（Network Commands）設為「開啟」（ON）
     →「網絡指令連接埠」（Network Command Port）保持 55355
     ・找不到「網絡」？先到 設定 → 使用者介面（User Interface）
       → 開啟「顯示進階設定」（Show Advanced Settings）
  3. 用 ⌘Q 完全結束 RetroArch 再打開，確認「網絡指令」仍然是開啟。
     ・每部電腦都要各自開啟一次；重新安裝 RetroArch 後也要再開。


  ── 用 DuckStation 的話 ──
  需要：DuckStation、PS1 BIOS、遊戲（同上）。
  1. DuckStation → 設定（Settings）→ 進階（Advanced），勾選「Show Debug Menu」
     （簡體中文介面：设置 → 高级 → 显示调试菜单）。
  2. 設定視窗左邊會多了「Debugging」（调试）一頁，打開它，
     在選項表中開啟「Enable GDB Server」（启用GDB服务器），
     「GDB Server Port」（GDB服务器端口）保持 2345。
  3. 設定立即生效；如果小程式連不上，重新載入遊戲一次。
  ・小程式會自動偵測你用的是 RetroArch 還是 DuckStation，不用另外設定。
  ・小程式連上 DuckStation 的一瞬間，遊戲會暫停並立即自動繼續，這是正常的。


--------------------------------------------------
第 4 步：開始遊戲
--------------------------------------------------
  在 RetroArch（用上面的 PS1 核心）或 DuckStation 載入遊戲，從記憶卡讀檔（或開新遊戲），
  進入可以操控精靈的遊戲畫面。不需要先存檔。


--------------------------------------------------
第 5 步：開啟小程式
--------------------------------------------------
  雙擊「Mac 啟動（只限這部電腦）.command」，會開一個終端機視窗。

  第一次會出現「Apple 無法驗證……」的警告，這是 Mac 對網上下載檔案的正常保護：
  1. 按「完成」（不要按「移到垃圾桶」）。
  2. 打開「系統設定」→「私隱與安全性」，捲到最下面，
     按「仍要打開」，再輸入電腦密碼或用 Touch ID 確認。
  3. 再雙擊一次啟動檔，彈出視窗時選「打開」。
  （想先檢查：對 .command 按右鍵 →「打開方式」→「文字編輯」，
    內容只有約 15 行，只是找出 Python，然後運行同一資料夾的 dw1_bridge.py。）

  終端機視窗出現「已連接 RetroArch」或「已連接 DuckStation」就是成功。
  ★ 玩遊戲期間，終端機視窗要一直開著（可以縮小，不要關閉）。

  另一個方法（完全不經過警告）：打開終端機，輸入 cd 加一個空格，
  把這個資料夾拖進終端機視窗，按 Enter，再輸入 python3 dw1_bridge.py 按 Enter。


--------------------------------------------------
第 6 步：開啟網頁
--------------------------------------------------
  用瀏覽器（Safari、Chrome 都可以）在網址列輸入：
      http://127.0.0.1:55356/
  按 Enter。網頁左上角的精靈資料欄出現綠點＝實時中。
  在遊戲裏訓練、吃東西、戰鬥，網頁數值會跟著自動更新。

  ・不要直接雙擊 index.html，要用上面的網址。
  ・網址是 http（不是 https）。
  ・玩漢化版：網頁頂部「遊戲版本」選「自動偵測」，用字會和遊戲一樣。
  ・玩完：在終端機視窗按 Control＋C，或直接關閉該視窗。下次只需做第 4～6 步。


--------------------------------------------------
常見問題
--------------------------------------------------
▶ 雙擊 .command 後顯示「找不到可用的 Python 3」
  → 重做第 2 步，安裝完成後再雙擊。

▶ 終端機或網頁顯示「RetroArch 沒有回應」或「都沒有回應」
  → RetroArch 有沒有開著、有沒有載入遊戲？
  → 最常見：未開啟「網絡指令」，重做第 3 步第 2 點。
  → RetroArch 停在選單時有時不回應，回到遊戲畫面即可。

▶ 用 DuckStation 時顯示「DuckStation 沒有回應」
  → DuckStation 有沒有開著、有沒有載入遊戲？
  → 未開啟「Enable GDB Server」（見第 3 步），或開啟後重新載入遊戲一次。

▶「已連上 RetroArch，但讀不到遊戲記憶體」
  → 請用 Beetle PSX、SwanStation 或 PCSX ReARMed 核心載入遊戲。

▶「種類編號不合理」
  → 遊戲還在標題畫面或讀取中，進入遊戲畫面後會自動恢復。
  → 一直這樣：遊戲不是日版 Rev 1（SLPS-01797）或其漢化版。

▶ 終端機顯示「連接埠 55356 已被使用」
  → 小程式已經在另一個視窗運行，關掉多出來的那個即可。

▶ Mac 詢問是否允許 Python 接受連入的網絡連線
  → 用「只限這部電腦」版本時不應出現；出現的話可按「拒絕」，不影響使用。
  → 用「iPad 也可以看」版本才需要按「允許」。

更多說明（iPad 副螢幕、進階用法）請看「使用說明.txt」。
