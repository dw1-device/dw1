DW1 暴龍機 實時版　Windows 安裝說明
==================================================

照下面 1 → 6 步做，大約 15 分鐘。
遇到問題，請把「畫面上的字」拍照或截圖傳回來，並說明做到第幾步。


這是甚麼？
  你用 RetroArch 玩《數碼暴龍世界》（PS1 日版 Rev 1 或其繁體中文漢化版）時，這個工具會即時讀出
  遊戲裏的數值（能力、疲勞、失誤、背包等），在瀏覽器網頁上自動更新，
  還會提示精靈肚餓、想大便、想睡，以及進化預測。

安全嗎？
  ✔ 沒有 .exe。資料夾裏全部是可以用「記事本」打開檢查的純文字檔。
  ✔ 不連接互聯網，只和你電腦上的 RetroArch 溝通。
  ✔ 只讀不寫：不會改動遊戲、存檔或任何檔案，不需要管理員權限。
  ✔ 不想用了，刪除整個資料夾即可。


--------------------------------------------------
第 1 步：解壓縮
--------------------------------------------------
  在收到的 .zip 檔案上按右鍵 →「解壓縮全部…」→「解壓縮」。
  ★ 不要直接在壓縮檔裏面雙擊檔案，一定要先解壓縮。
  解壓後的資料夾裏應該有：
    index.html
    dw1_bridge.py
    Windows 啟動（只限這部電腦）.bat
    Windows 啟動（iPad 也可以看）.bat
    先讀我：Windows 安裝說明.txt（就是這份）
    使用說明.txt（完整版說明，遇到問題時參考）


--------------------------------------------------
第 2 步：安裝 Python 3（只需做一次）
--------------------------------------------------
  1. 用瀏覽器開 https://www.python.org/downloads/windows/
     按最新版的「Download Windows installer (64-bit)」。
  2. 開啟下載的安裝程式。
     ★★ 第一頁最底有一個「Add python.exe to PATH」，一定要打勾 ★★
     然後按「Install Now」，等它完成，按「Close」。
  3. 不用重新開機。

  已經安裝過 Python？可以跳過這一步。
  不肯定的話：按開始，輸入 cmd 開「命令提示字元」，打 py --version
  按 Enter，顯示「Python 3.x.x」就是已經有了。


--------------------------------------------------
第 3 步：設定 RetroArch（只需做一次）
--------------------------------------------------
  需要：RetroArch、PS1 核心、PS1 日版 BIOS（例如 scph5500.bin）、
        遊戲《數碼暴龍世界》日版 Rev 1（SLPS-01797）或其繁體中文漢化版。
        其他版本讀不到。

  1. 下載核心：
     主選單 → 線上更新（Online Updater）→ 核心下載器（Core Downloader）
     → 「Sony - PlayStation (Beetle PSX HW)」或「Beetle PSX」
     （也可以用 SwanStation 或 PCSX ReARMed 核心）
  2. 開啟「網絡指令」：
     主選單 → 設定（Settings）→ 網絡（Network）
     → 「網絡指令」（Network Commands）設為「開啟」（ON）
     → 「網絡指令連接埠」（Network Command Port）保持 55355
     ・找不到「網絡」？先到 設定 → 使用者介面（User Interface）
       → 開啟「顯示進階設定」（Show Advanced Settings）
  3. 保存設定：主選單 → 設定檔（Configuration File）→「儲存目前設定」
     （Save Current Configuration）。或者完全關閉 RetroArch 再打開，
     看看「網絡指令」是否仍然是開啟。


--------------------------------------------------
第 4 步：開始遊戲
--------------------------------------------------
  用上面的 PS1 核心載入遊戲，從記憶卡讀檔（或開新遊戲），進入可以操控精靈的
  遊戲畫面。不需要先存檔。


--------------------------------------------------
第 5 步：開啟小程式
--------------------------------------------------
  雙擊「Windows 啟動（只限這部電腦）.bat」，會開一個黑色視窗。

  第一次可能出現警告，這是 Windows 對網上下載檔案的正常保護：
  ・「開啟檔案 - 安全性警告」→ 按「執行」
  ・藍色的「Windows 已保護您的電腦」→ 按「其他資訊」→「仍要執行」
  （想先檢查：對 .bat 按右鍵 →「在記事本中編輯」，內容只有約 20 行，
    只是找出 Python，然後運行同一資料夾的 dw1_bridge.py。）

  黑色視窗出現「已連接 RetroArch」就是成功。
  ★ 玩遊戲期間，黑色視窗要一直開著（可以縮小，不要關閉）。


--------------------------------------------------
第 6 步：開啟網頁
--------------------------------------------------
  用瀏覽器（Edge、Chrome 都可以）在網址列輸入：
      http://127.0.0.1:55356/
  按 Enter。網頁左上角的精靈資料欄出現綠點＝實時中。
  在遊戲裏訓練、吃東西、戰鬥，網頁數值會跟著自動更新。

  ・不要直接雙擊 index.html，要用上面的網址。
  ・網址是 http（不是 https）。
  ・玩完：關閉黑色視窗即可。下次只需做第 4～6 步。


--------------------------------------------------
常見問題
--------------------------------------------------
▶ 雙擊 .bat 後顯示「找不到 Python 3」
  → 重做第 2 步，記得勾選「Add python.exe to PATH」，然後再雙擊 .bat。

▶ 雙擊 .bat 後視窗一閃即逝
  → 確認已經解壓縮（第 1 步），而且 .bat 和 dw1_bridge.py 在同一個資料夾。

▶ 黑色視窗或網頁顯示「RetroArch 沒有回應」
  → RetroArch 有沒有開著、有沒有載入遊戲？
  → 最常見：未開啟「網絡指令」，重做第 3 步第 2 點，並確認已保存。
  → RetroArch 停在選單時有時不回應，回到遊戲畫面即可。

▶「已連上 RetroArch，但讀不到遊戲記憶體」
  → 請用 Beetle PSX、SwanStation 或 PCSX ReARMed 核心載入遊戲。

▶「種類編號不合理」
  → 遊戲還在標題畫面或讀取中，進入遊戲畫面後會自動恢復。
  → 一直這樣：遊戲不是日版 Rev 1（SLPS-01797）或其漢化版。

▶ 黑色視窗顯示「連接埠 55356 已被使用」
  → 小程式已經在另一個視窗運行，關掉多出來的那個即可。

▶ 防火牆詢問是否允許 Python 存取網絡
  → 用「只限這部電腦」版本時不應出現；出現的話可按「取消」，不影響使用。
  → 用「iPad 也可以看」版本才需要按「允許存取」（勾選「私人網絡」）。

更多說明（iPad 副螢幕、進階用法）請看「使用說明.txt」。
