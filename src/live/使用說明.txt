DW1 暴龍機 — 實時版　首次使用完整教學
==================================================

實時版是甚麼？
  你在電腦上用 RetroArch 或 DuckStation 玩《數碼暴龍世界》（PS1 日版 Rev 1，或其繁體中文漢化版）時，
  實時版會即時讀出遊戲裏的數值（能力、疲勞、失誤、壽命、背包等），
  在網頁上自動更新：訓練、戰鬥、吃東西後不用存檔，進化預測就會跟著變。

  用手機、平板或其他模擬器？請用「網頁版」：
  https://dw1-device.github.io/dw1/ （上載記憶卡存檔即可，不用安裝任何東西）


--------------------------------------------------
一、安全說明（請先讀）
--------------------------------------------------
這個資料夾裏只有以下檔案，全部都是可以用文字編輯器打開查看的純文字：

  index.html                     網頁本身（和網頁版一樣，離線也能開）
  dw1_bridge.py                  小程式（Python 原始碼，約 250 行）
  Mac 啟動（……）.command         Mac 用的啟動檔（約 15 行，只在 Mac 版）
  Windows 啟動（……）.bat         Windows 用的啟動檔（約 20 行，只在 Windows 版）
  先讀我：Mac／Windows 安裝說明.txt  快速安裝步驟
  使用說明.txt                   本說明

保證：
  ✔ 不是執行檔（.exe／.app），沒有隱藏的程式碼。每個檔案都可以用
    「文字編輯」（Mac）或「記事本」（Windows）打開，看到全部內容。
  ✔ 不需要互聯網。小程式只和你自己電腦上的模擬器（RetroArch 或 DuckStation）溝通
    （位址 127.0.0.1，即「這部電腦」）。網頁也不會自動連接任何網站；
    網頁上的 GitHub 等連結，只有你親手按下才會開。
  ✔ 只讀不寫。小程式只「讀取」遊戲記憶體，不會改動遊戲、存檔或任何檔案，
    也不會在電腦上安裝任何東西、不需要管理員權限。
  ✔ 移除方法：關閉小程式視窗，刪除這個資料夾即可，不會留下任何東西。

唯一需要另外安裝的是 Python 3（一個免費的程式語言），請只從官方網站下載：
  https://www.python.org/downloads/
（Mac 也可以用 Apple 內建提供的版本，見下面。）

為甚麼開啟時電腦會出現警告？
  Mac 和 Windows 對「從網上下載、未經付費簽署」的檔案都會先警告一次，
  這是正常的保護措施，不代表檔案有問題。你可以先用文字編輯器打開檔案檢查，
  確認後再按「仍要打開／仍要執行」。


--------------------------------------------------
二、需要準備
--------------------------------------------------
  1. 電腦：Mac 或 Windows（Linux 亦可，用終端機手動運行）
  2. 模擬器（擇一）：
     ・RetroArch（免費）：https://www.retroarch.com/
       PS1 核心「Beetle PSX」（或「SwanStation」、「PCSX ReARMed」），在 RetroArch 裏下載
     ・DuckStation（免費）：https://www.duckstation.org/
  3. PS1 日版 BIOS（例如 scph5500.bin），放在模擬器的 BIOS／system 資料夾
  4. 遊戲：數碼暴龍世界 日版 Rev 1（SLPS-01797），或用它製作的繁體中文漢化版（漢化 1.0.0）。
     其他版本（美版、日版初版等）記憶體位置不同，讀不到。
     用漢化版時，網頁頂部「遊戲版本」選「自動偵測」或「繁體中文漢化版」，用字就會和遊戲一樣。
  5. Python 3（見第四、五節）


--------------------------------------------------
三、設定模擬器（★每部電腦都要各自做一次★）
--------------------------------------------------
  ── 用 RetroArch 的話 ──
  1. 主選單 → 線上更新 → 核心下載器 → 下載「Sony - PlayStation (Beetle PSX)」
  2. 主選單 → 設定 → 網絡 → 把「網絡指令」（Network Commands）開啟
     連接埠保持 55355（不要改）
     ・找不到「網絡」：先到 設定 → 使用者介面 → 開啟「顯示進階設定」
  3. 主選單 → 設定 → 使用者介面 底部，或主選單的「儲存目前設定」，保存設定
  4. 用 Beetle PSX 核心載入遊戲，從記憶卡讀檔，進入遊戲畫面

  注意：RetroArch 的雲端同步（iCloud 等）不會同步「網絡指令」這個設定。
        換一部電腦玩，記得在那部電腦再開啟一次，否則實時版會顯示
        「RetroArch 沒有回應」。


  ── 用 DuckStation 的話（取代上面的 RetroArch 設定） ──
  1. DuckStation → 設定（Settings）→ 進階（Advanced），勾選「Show Debug Menu」
     （簡體中文介面：设置 → 高级 → 显示调试菜单）
  2. 設定視窗左邊多了「Debugging」（调试）一頁：開啟「Enable GDB Server」
     （启用GDB服务器），「GDB Server Port」保持 2345
  3. 設定立即生效；GDB 伺服器只在遊戲運行時開啟。連不上時重新載入遊戲一次
  4. 小程式會自動偵測 RetroArch 或 DuckStation，不用另外設定
     （想指定：終端機運行 python3 dw1_bridge.py --emu duckstation）
  ・小程式連上 DuckStation 的一瞬間，遊戲會暫停並立即自動繼續，這是正常的。
  ・如果你本來暫停了 DuckStation，小程式連上時會令遊戲繼續運行。


--------------------------------------------------
四、Mac 使用者
--------------------------------------------------
【第一次：安裝 Python】
  1. 打開「終端機」（應用程式 → 工具程式 → 終端機）
  2. 輸入 python3 --version 然後按 Enter
     ・如果顯示「Python 3.x.x」：已經有了，跳到下一步
     ・如果彈出視窗要求安裝「命令列開發者工具」：按「安裝」，等完成
       （這是 Apple 官方提供的，約幾分鐘）
     ・或者到 https://www.python.org/downloads/macos/ 下載安裝

【第一次：允許打開啟動檔】
  雙擊「Mac 啟動（只限這部電腦）.command」時，Mac 可能說
  「無法打開，因為 Apple 無法驗證……」：
  1. 按「完成」（不要按「移到垃圾桶」）
  2. 打開「系統設定 → 私隱與安全性」，捲到最下面，按「仍要打開」，
     再輸入電腦密碼確認
  （另一個方法：在終端機輸入 xattr -cr 加一個空格，把整個實時版資料夾
    拖進終端機視窗，按 Enter，就會一次解除這個資料夾所有檔案的警告）

【每次使用】
  1. 開 RetroArch 或 DuckStation，載入遊戲，進入遊戲畫面
  2. 雙擊「Mac 啟動（只限這部電腦）.command」，會開一個終端機視窗
     看到「已連接 RetroArch」或「已連接 DuckStation」＝成功（終端機視窗要一直開著）
  3. 用瀏覽器（Safari／Chrome 都可以）開 http://127.0.0.1:55356/
     網頁左上角資料欄出現綠點＝實時中
  4. 玩完：在終端機視窗按 Control＋C，或直接關閉該視窗


--------------------------------------------------
五、Windows 使用者
--------------------------------------------------
【第一次：安裝 Python】
  1. 到 https://www.python.org/downloads/windows/ 下載「Windows installer (64-bit)」
  2. 開啟安裝程式，★第一頁最底記得勾選「Add python.exe to PATH」★
     然後按「Install Now」
  3. 完成後不用重新開機

【第一次：解壓縮和允許執行】
  1. 下載的是 .zip 的話，先按右鍵 →「解壓縮全部」，不要直接在壓縮檔裏雙擊
  2. 雙擊「Windows 啟動（只限這部電腦）.bat」時，可能出現：
     ・「開啟檔案 - 安全性警告」：按「執行」
     ・藍色的「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」
  （想先檢查：對 .bat 按右鍵 →「編輯」或用記事本打開，內容只是找出 Python，
    再運行同一資料夾的 dw1_bridge.py）

【每次使用】
  1. 開 RetroArch 或 DuckStation，載入遊戲，進入遊戲畫面
  2. 雙擊「Windows 啟動（只限這部電腦）.bat」，會開一個黑色視窗
     看到「已連接 RetroArch」或「已連接 DuckStation」＝成功（黑色視窗要一直開著）
  3. 用瀏覽器（Edge／Chrome 都可以）開 http://127.0.0.1:55356/
  4. 玩完：在黑色視窗按 Ctrl＋C，或直接關閉該視窗


--------------------------------------------------
六、用 iPad／手機做副螢幕（選用）
--------------------------------------------------
  1. 電腦和 iPad／手機連同一個 Wi-Fi
  2. 改為雙擊「iPad 也可以看」的啟動檔（Mac 是 .command，Windows 是 .bat）
  3. 視窗會顯示一行「iPad／手機（同一個 Wi-Fi）：用 Safari 開 http://192.168.x.x:55356/」
     在 iPad／手機的瀏覽器輸入那個位址
  4. 電腦第一次會詢問網絡權限：
     ・Mac：「是否允許 Python 接受連入的網絡連線」→ 按「允許」
     ・Windows 防火牆：勾選「私人網絡」→ 按「允許存取」
  5. 小提示：在 Safari 按「分享 → 加入主畫面」，下次一按就開
  注意：同一個 Wi-Fi 的人都能看到遊戲數值（只能看、不能改）。
        咖啡店等公眾 Wi-Fi 請用「只限這部電腦」。


--------------------------------------------------
七、遇到問題？按畫面顯示的情況對照
--------------------------------------------------
網頁上「實時連線」頁和小程式視窗都會顯示目前的狀態，照下面處理。
處理好之後網頁會自動連上，不用重開小程式。

▶ 雙擊啟動檔後沒有反應／一閃即逝
  ・Mac：見第四節「允許打開啟動檔」
  ・Windows：視窗應該會停住並顯示訊息；如果顯示「找不到 Python 3」，
    照第五節安裝 Python，記得勾選「Add python.exe to PATH」，然後再雙擊
  ・確認 dw1_bridge.py 和啟動檔在同一個資料夾（Windows 要先解壓縮）

▶「RetroArch 沒有回應」
  ・RetroArch 有沒有開著？遊戲有沒有載入？
  ・最常見：這部電腦的 RetroArch 未開啟「網絡指令」→ 見第三節第 2 步
    （換了電腦、重裝 RetroArch 都要重新開啟）
  ・連接埠是不是 55355？
  ・RetroArch 停在選單時有時不回應，回到遊戲畫面就好

▶「DuckStation 沒有回應」／「RetroArch 和 DuckStation 都沒有回應」
  ・模擬器有沒有開著？遊戲有沒有載入？
  ・DuckStation：未開啟「Enable GDB Server」（見第三節），或開啟後重新載入遊戲一次
  ・剛關閉或重新載入遊戲：等一兩秒會自動重新連上

▶「已連上 RetroArch（或 DuckStation），但讀不到遊戲記憶體」
  ・網絡指令正常，但未載入遊戲，或用了不支援的核心
  ・請用 Beetle PSX、SwanStation 或 PCSX ReARMed 核心載入遊戲

▶「種類編號不合理」
  ・遊戲還在標題畫面或讀取中：進入遊戲畫面後會自動恢復
  ・一直這樣：遊戲不是日版 Rev 1（SLPS-01797）或其漢化版

▶ 瀏覽器打不開 http://127.0.0.1:55356/（或網頁顯示「未連上」）
  ・小程式視窗有沒有開著？關了就要重新雙擊啟動檔
  ・小程式視窗顯示「連接埠 55356 已被使用」：小程式已經在另一個視窗運行，
    關掉多出來的那個即可
  ・不要直接雙擊 index.html 打開，要用上面的位址
  ・位址是 http（不是 https）

▶ 網頁數值和遊戲不一樣／沒有更新
  ・看網頁左上角有沒有綠點；沒有的話看「實時連線」頁顯示的原因
  ・用了「Load State」（即時存檔）後，數值會跳回那一刻，這是正常的

▶ 存檔相關提醒
  ・RetroArch 只在「關閉遊戲」時才把記憶卡存檔寫入 .srm 檔案。
    換存檔檔案前，請先完全關閉 RetroArch，再用「從記憶卡讀檔」，不要用 Load State。
  ・實時版只讀取遊戲記憶體，與存檔放在哪裏（例如 iCloud）無關。


--------------------------------------------------
八、進階：用終端機手動運行
--------------------------------------------------
  1. 打開終端機（Windows：命令提示字元）
  2. 輸入 cd 加一個空格，把這個資料夾拖進視窗，按 Enter
  3. 輸入：
       Mac／Linux：python3 dw1_bridge.py
       Windows：  py dw1_bridge.py
     加 --lan 就是「iPad 也可以看」模式；加 --test 只讀一次並顯示結果
  4. 瀏覽器開 http://127.0.0.1:55356/

有問題或發現資料錯誤，歡迎按網頁底部的「資料修正建議」告訴我們。
