DW1 暴龍機 — 實時版（RetroArch 實時連線，電腦用）
==========================================

需要：
- Mac 或 Windows（Linux 亦可）上的 RetroArch，核心用「Beetle PSX」或「SwanStation」
- 數碼暴龍世界 日版 Rev 1（SLPS-01797）
- Python 3
  Mac：第一次在終端機打 python3 時，如果提示安裝「命令列開發工具」，按安裝即可
  Windows：到 https://www.python.org/downloads/windows/ 下載安裝；安裝第一頁記得勾選「Add python.exe to PATH」

一、設定 RetroArch（只需做一次）
1. 主選單 → 線上更新 → 核心下載器 → 下載「Sony - PlayStation (Beetle PSX)」
   （PS1 核心需要日版 BIOS 檔，例如 scph5500.bin，放在 RetroArch 的 system 資料夾）
2. 設定 → 網絡 → 把「網絡指令」(Network Commands) 開啟，連接埠保持 55355
   （找不到的話：設定 → 使用者介面 → 開啟「顯示進階設定」）
3. 用 Beetle PSX 核心載入遊戲，讀取你的存檔，進入遊戲畫面

二、開啟小程式（最簡單：雙擊啟動檔）
【Mac】
- 雙擊「Mac 啟動（只限這部電腦）.command」：網頁只在這部 Mac 開
- 雙擊「Mac 啟動（iPad 也可以看）.command」：同一個 Wi-Fi 的 iPad／手機也可以開
  第一次雙擊時，如果 Mac 說「Apple 無法驗證……」：按「完成」（不要按「移到垃圾桶」），然後擇一：
  ① 終端機打 xattr -cr 加一個空格，再把這個資料夾拖進去，按 Enter（一次解除全部檔案）
  ② 系統設定 → 私隱與安全性 → 捲到最下 → 按「仍要打開」
【Windows】
- 雙擊「Windows 啟動（只限這部電腦）.bat」：網頁只在這部電腦開
- 雙擊「Windows 啟動（iPad 也可以看）.bat」：同一個 Wi-Fi 的 iPad／手機也可以開
  啟動檔是純文字，可以用記事本打開查看內容：只是找出 Python，再運行同一資料夾的 dw1_bridge.py。
  第一次雙擊時，如果出現安全性警告或藍色的「Windows 已保護您的電腦」：按「執行」，或「其他資訊」→「仍要執行」。
  如果顯示「找不到 Python 3」：照畫面指示安裝 Python，記得勾選「Add python.exe to PATH」。
  用「iPad 也可以看」時，Windows 防火牆會詢問：勾選「私人網絡」，按「允許存取」。
- 也可以用終端機手動運行（見下面）

用終端機手動運行：
1. dw1_bridge.py 和 index.html 要放在同一個資料夾
2. 開「終端機」（Windows：開「命令提示字元」），打：
      cd （把這個資料夾拖進終端機視窗，會自動填上位置）
      python3 dw1_bridge.py        （Windows 打 py dw1_bridge.py）
   看到「已連接 RetroArch」就成功了
3. 用瀏覽器開 http://127.0.0.1:55356/
   網頁會自動連線，左上角資料欄出現綠點＝實時中

三、用 iPad 做副螢幕
1. 電腦和 iPad 連同一個 Wi-Fi
2. 雙擊「iPad 也可以看」的啟動檔（Mac 是 .command，Windows 是 .bat），視窗會顯示一行
      iPad／手機（同一個 Wi-Fi）：用 Safari 開  http://192.168.x.x:55356/
3. 在 iPad 的 Safari 輸入那個位址，網頁會自動連線
4. Mac 第一次問「是否允許 Python 接受連入的網絡連線」，按「允許」
   （之前按了「拒絕」的話：系統設定 → 網絡 → 防火牆 → 選項，把 Python 改為允許）
5. 小提示：在 Safari 按「分享 → 加入主畫面」，下次一按就開
注意：同一個 Wi-Fi 的人都能看到遊戲數值（只能看、不能改），公眾 Wi-Fi 請用「只限這部電腦」

四、使用
- 之後每秒自動更新：能力、疲勞、生命、體重、失誤、教養、心情、壽命、年齡、時間、已學招式、已加入城鎮的精靈、背包、倉庫、食物加成、各項目訓練次數
- 實時版沒有「上載存檔」；在手機或沒有 RetroArch 時，用網頁頂部的「網頁版」連結
- 訓練、戰鬥、吃東西後不用存檔，進化預測、存檔分析、食堂當值都會跟著遊戲變化
- 結束時在終端機（Windows 是黑色的命令視窗）按 Ctrl+C，或直接關閉視窗

疑難：
- 「RetroArch 沒有回應」：檢查「網絡指令」已開啟、遊戲已在運行、沒有改過連接埠
- 「種類不合理」：遊戲在標題畫面或讀取中，進入遊戲後會自動恢復
- 只支援日版 Rev 1；其他版本的記憶體位置不同

小程式只讀取遊戲記憶體，不會改動遊戲，也不會連接互聯網。
